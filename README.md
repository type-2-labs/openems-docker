# openems-docker

[openEMS](https://openems.de) v0.37.0 (FDTD electromagnetic solver for antennas and RF) with CSXCAD and
the Python interface, headless (no AppCSXCAD GUI).

Image: `ghcr.io/type-2-labs/openems:0.37.0` (built by GitHub Actions on every push to `main`).

- `openEMS` on `PATH`; Python venv `/opt/openEMS/venv` on `PATH`: `import CSXCAD, openEMS`
